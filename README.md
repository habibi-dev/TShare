# اشتراک امن و موقت متن - TShare

سرویس TShare یک سرویس **اشتراک‌گذاری امن و موقت متن** است که با Rust/Axum ساخته شده و بدون نیاز به ثبت‌نام، لینک کوتاه برای متن تولید می‌کند.

## فیچرها
- ایجاد لینک کوتاه ۶ کاراکتری برای متن.
- انقضای خودکار لینک (از ۵ دقیقه تا ۲۴ ساعت).
- محدودیت تعداد مشاهده.
- حالت یک‌بارمصرف.
- محافظت با رمز عبور.
- محدودسازی مشاهده بر اساس IP.
- حذف اشتراک با توکن اختصاصی.
- صفحه تاریخچه لینک‌های ساخته‌شده در مرورگر کاربر.

## معماری و تکنولوژی
- Backend: `Rust` + `Axum`
- Data: `Redis` (ذخیره موقت اشتراک‌ها با TTL)
- Metadata/Settings: `SQLite` با `SeaORM`
- Template Engine: `Askama`
